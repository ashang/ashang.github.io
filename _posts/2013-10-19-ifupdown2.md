


Debian’s ifupdown
! Default Network Interface Manager for Debian
! Configuration file : /etc/network/interfaces
! Network interfaces represented by “iface” sections

iface br100
	bridge-ports swp1 swp2
	bridge-stp on


Does not understand interface dependency
! Problems with provisioning interfaces at scale
! No support for incremental changes to interface config
! No support to query/validate running configuration


ifupdown2

! Backward compatibility with debian ifupdown

Ordered Network Interface dependency
relationship handling
! Incremental changes and query live
configuration

ifupdown2 is a new implementation of debian’s network interface manager ifupdown. It understands interface dependency relationships, simplifies interface configuration, extends ifquery to support interface config validation, supports JSON and more.

The ifupdown2 package provides required infrastructure to parse, schedule and manage interface configuration. It also provides python addon modules for network interface configuration. The default python addon modules shipped with the package include bridge, vlan, bond, mstp, address modules and more.
