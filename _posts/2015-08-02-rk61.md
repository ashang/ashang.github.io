# `Fn` + `Left Ctrl`

Activate second function of combination keys (except arrow keys).
Press again to restore the 9 keys' (Y, U, I, H, J, K, N, M, <) main function, but other combination keys will still use their second function.

Press a third time to restore combination keys' main function

# `Fn` + `Tab`

Switch wired / Bluetooth mode.

`Fn` + `P`  (hold for 3 seconds) Enter pairing mode
