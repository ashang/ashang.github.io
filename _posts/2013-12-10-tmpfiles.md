    change tmp-files control by systemd

    The control conf files are:

    /etc/tmpfiles.d/*.conf
    /run/tmpfiles.d/*.conf
    /usr/lib/tmpfiles.d/*.conf

    These files will control the tmp-files that was used by system or user.
    the 'systemd-tmpfiles' will check the *.conf files to manage all things.

    Before change tmp-files, should write a correct line on *.conf file.

```
# /usr/lib/tmpfiles.d/tmp.conf
# See tmpfiles.d(5) for details

# Clear tmp directories separately, to make them easier to override
D /tmp 1777 root root -
d /tmp/log 1777 root root -
f /tmp/log/wtmp 0664 root utmp -

# Exclude namespace mountpoints created with PrivateTmp=yes
x /tmp/systemd-private-%b-*
X /tmp/systemd-private-%b-*/tmp
x /var/tmp/systemd-private-%b-*
X /var/tmp/systemd-private-%b-*/tmp

# /usr/lib/tmpfiles.d/var.conf
# See tmpfiles.d(5) for details

d /var 0755 - - -

L /var/run - - - - ../run

d /var/log 0755 - - -
f /var/log/btmp 0600 root utmp -

d /var/cache 0755 - - -

d /var/lib 0755 - - -
d /var/lib/container 0700 - - -

d /var/spool 0755 - - -

```
