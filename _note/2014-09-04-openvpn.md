
Permission denied errno=13 when starting openvpn via systemctl.

    $ sudo systemctl start openvpn@server

Check status:

    $ sudo systemctl status openvpn@server

    Socket bind failed on local address [AF_INET][undef]:1023 Permission denied (errno=13)

But it is OK to run manually:

    $ sudo openvpn --cd /etc/openvpn/ --config server.conf

Solution:

    $ sudo semanage port -a -t openvpn_port_t -p udp 1023
