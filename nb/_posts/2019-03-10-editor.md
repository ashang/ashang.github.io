
Issue.

```sh
# crontab -e
/bin/sh: line 1: /usr/bin/nano: No such file or directory
crontab: "/usr/bin/nano" exited with status 127
```

```sh
# echo $EDITOR
/usr/bin/nano
```

Solution.

```sh
# EDITOR=/usr/bin/vi crontab -e
crontab: installing new crontab
```

Or export into env for later reference.

```sh
# export EDITOR=/usr/bin/vi
```

Or put that into the shell rc file for new shell instances.

More.

```sh
# grep EDITOR /etc/ -r
/etc/mail.rc:# When entering compose mode, directly startup into $EDITOR, as via `~e'.
/etc/environment:EDITOR=/usr/bin/nano

# pacman -Qo /etc/environment
/etc/environment is owned by pam 1.5.2-1
```

So changing there also helps for new pam env.
