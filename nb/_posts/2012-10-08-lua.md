
Lua has automatic memory management and increment of garbage collection.

It is very easy to embed into other application.


- It has been efficient in-memory usages.
- It is very easy to insert in C programs.
- It doesn’t support general-purpose exception handling.
- It doesn’t support features like classes and inheritances.

## Comments

Lua also offers block comments, which start with --[[ and run until the corresponding ]].

Block comments must have exactly 2 hyphens and 2 brackets at the beginning and end.

The sequence ---[[ does not start a block comment, so the line starting with -- is just a line comment.

### Nesting comments

Double square brackets allow nesting, but they require one or more = inserted in the outer-most brackets to distinguish them. It doesn't matter how many = are inserted, as long as the number is the same in the beginning and ending brackets.

    --[===[
    multiple
    lines, possible with nested block comments.
    --]===]
