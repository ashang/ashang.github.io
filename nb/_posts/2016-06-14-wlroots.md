

wlroots完全基于linux的DRM（Direct Rendering Manager）（KMS、GBM）。而Nvidia的闭源驱动一直以来都是自己实现了一套EGLstream，不用linux内核的GBM，所以搞的wlroots的开发者们完全不想再花功夫支持Nvidia了。不过这个情况已经有了改观，目前最新的Nvidia 495.xx闭源驱动已经支持了linux内核的GBM和DMA-BUF，也就意味着理论上wlroots在最新的Nvidia驱动上是可用的


### Input configuration
#
# Example configuration:
#
   input "1267:12668:MSFT0001:00_04F3:317C_Touchpad" {
       dwt enabled
       tap enabled
       natural_scroll enabled
       middle_emulation enabled
   }

   input * accel_profile flat
# You can get the names of your inputs by running: swaymsg -t get_inputs
# Read `man 5 sway-input` for more information about this section.

这是关于鼠标和触摸板的设置，怎么设置的注释已经很清楚了，看man 5 sway-input就行。

这是关于屏幕和桌面壁纸的设置。

xwayland enabled

这是关于是否兼容X11协议程序的设置，目前很多桌面程序仍然不支持wayland，建议开启。这一行得自己加上。

另外想要开启Xwayland，得安装

sudo pacman -S xorg-xwayland
