
# Example on centos

Append the kernel command line with `rd.break` after kernel.

This will break just before control is handed from the initramfs to the actual system, leaving you the initramfs debug shell.

Or, replace the `ro` to `rw single` after kernel.

```
# mount -o remount,rw /sysroot
# chroot /sysroot
# chage -l root
# chage -E -1 root
# passwd root  
# touch /.autorelabel
```

Check the /var/log/messages for any error messages.
