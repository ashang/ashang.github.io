This issue is related to the time stamp update of the file access on the rootfs.

The noatime option should be added for root / at /etc/fatab.

 

This issue is related Xinguard as well. There are many IDE error on P-3780 logging file.

The update of file access time is updated every 5 seconds, which is the commit internal of the journaling.

 

If the access time update is disabled, there is no much WRITE action anymore.

This should fix both Mezocliq and Xinguard issue.

We will add it into next release.
