wgethttps://www.kernel.org/pub/linux/kernel/projects/backports/stable/v4.14-rc2/backports-4.14-rc2-1.tar.gz

安装依赖：

sudo apt-get install linux-headers-genericbuild-essential 

解压并安装：

tar –zxvf backports-4.14-rc2-1.tar.gz

cd backports-4.14-rc2-1

make defconfig-ath9k

make

sudo make install

加载ath9k模块

sudo modprobe ath9k

显示网卡设备：lshw –C network

添加无线网卡配置：sudo vi /etc/network/interface

auto wlan0

iface wlan0 inet dhcp

禁用有线网卡：sudo ifconfig XXX down

启用无线网卡：sudo ifconfig wlan0 up


配置wpa_supplicant并连接wifi：

在/etc/下建立配置文件wpa_supplicant.conf，内容如下：

ctrl_interface=/var/run/wpa_supplicant

update_config=1

启动wpa_supplicant服务：

sudo wpa_supplicant -i wlan0 -c/etc/wpa_supplicant.conf &

通过wpa_cli配置wifi并连接：

sudo wpa_cli

添加网络连接：

add_network

返回0

设置该连接的参数：

set_network 0 ssid "wifi的ssid"

OK

set_network 0 psk "wifi的密码"

OK

使能网络连接：

enable_network 0

OK

看到CTRL-EVENT-CONNECTED信息，表示连接完成。

状态查看：status

保存设置：save

使用save命令可以保存当前的连接设置，下次wifi启动时会自动连接此AP
