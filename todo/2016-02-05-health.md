
# 每工作1小时休息一次，让眼睛离开电脑10~15分钟；

最好离开电脑屏幕，注视远方目标，直到清楚后再维持10几秒钟。

此外，还可以利用空闲时间闭闭眼睛，缓解眼睛的疲劳状态。例如： 打电话、去卫生间时闭闭眼、泡一杯茶、用餐时间

# 让眼球做运动

如果盯着电脑屏幕已经一小时了，你需要做一些眼球运动来缓解眼睛疲劳。
例如：
・向上望，同时呼一口气，再将视线移回中间，吸一口气。
・如此重复三次，最后再继续进行下侧、左侧及右侧的相同动作。
  
# 忙里偷闲眨眨眼

很多人因为太专注于工作，长时间盯着电脑屏幕忽视了眨眼睛，导致眼睛干涩不适。

眨眼睛的益处

・可以促进眼睛分泌泪水，并将含很多成分的眼泪均匀涂于眼球表面，
・保持眼部湿润。
・有助于清洁眼表面，也相当于给眼睛做一次按摩。

# 工作忙碌吸口气

据调查，很多人因为太专注盯着电脑，本能地使呼吸速度变缓。

吸口气也会对护眼有帮助吗？

而吸气是可以加速血液循环的，可以缓解眼睛疲劳。

# 坚持按摩解疲劳

・长期坚持不仅可以缓解眼睛酸涩疲劳，还有助于视力的改善。
・用双手大拇指轻轻揉按眉头下面、眼眶外上角处。
・用食指和中指指腹在眉弓处由内向外轻推至太阳穴轻按，重复5~6次。
