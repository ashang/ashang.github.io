# Overview

Aether (Yongda, located in Shenzhen, China) want a deployment of secure servers and secure routers.

The target secure servers would run CentOS 7.5, with latest Linux kernel.

They want to use PICOS as secure routers.

# Main features
- One time password for all users
    - login needs a OTP generated from mobile app;
    - The salted encrypted OTP generated from mobile app will be sent to PICOS, via API
    - Or, the salted encrypted OTP generated from PICOS via API at request will be return to mobile app
    - Only authorized access can be allowed

- Prevent normal users from escalating permissions
    - Need SELinux or AppArmor
    - L2/L3 needs change on login module
- Forbid root remote login
    - Done via sshd_config
- Root permission be separated from normal users,
    - Root contents should be encrypted
    - Root permission should be separated as Read/Write.
- Root authentication should be twice passwords
    - Co-hold by customers and Operating stakeholder.
    - 2FA might be needed
- Secure components can not be tampered or waived.


The only possible task that can be committed for working is the OTP part.

Solution team can help.

William Long had suggested that can be achieved by AAA. The AAA result can be sent to PICOS via current PICOS PAM modules.
No further concrete confirmation got from Aether.
